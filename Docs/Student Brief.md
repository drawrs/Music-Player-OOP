# Music Player OOP Challenge

Tujuan dari project ini adalah menganalisis kode yang sudah berjalan, lalu mengidentifikasi bagian-bagian yang bisa diperbaiki menggunakan prinsip OOP.

Fokus utama:
- encapsulation
- abstraction
- inheritance
- protocol

Yang perlu kamu lakukan:
- Pelajari struktur project dan pahami peran setiap model, player, view model, dan view.
- Temukan design issue atau code smell yang membuat code sulit dirawat atau sulit dikembangkan.
- Jelaskan kenapa issue tersebut penting.
- Usulkan perbaikan berbasis OOP.
- Implementasikan perbaikan yang menurutmu paling penting.

Batasan challenge:
- Jangan langsung rewrite semua file dari nol.
- Pertahankan behavior utama app: music dan podcast tetap bisa ditampilkan dan dikontrol.
- Usahakan refactor dilakukan bertahap dan masuk akal.

Pertanyaan panduan:
- Properti mana yang terlalu bebas diakses dari luar object?
- Apakah ada dua class yang punya behavior sangat mirip?
- Apakah UI atau view model terlalu tahu detail object tertentu?
- Apakah ada logic yang seharusnya bisa dipindahkan ke abstraction yang lebih umum?
- Kalau nanti ditambah tipe player baru, bagian mana yang paling cepat menjadi rumit?

Deliverable:
- daftar masalah yang kamu temukan
- alasan kenapa itu masalah
- refactor plan singkat
- implementasi perbaikan utama
